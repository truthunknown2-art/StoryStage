# F3-WP5 reference-comparison matrix

Comparison of the **actual Product v1 surfaces** (this branch's captures under
`screenshots/`, taken at 1920×1080, 1440×900, and 1024×800 on the real dev
server) against the accepted references:

- `docs/design/ai-copilot-studio/create-screen-reference.webp` (SHA-256 `e1a0b7f1…c06796d`)
- `docs/design/ai-copilot-studio/studio-timeline-reference.webp` (SHA-256 `2c0176f4…b3a9f0`)
- `docs/design/ai-copilot-studio/ai-copilot-concept-board.webp` (SHA-256 `984f3a66…62fc0f6`)
- `docs/design/ai-copilot-studio/README.md` (SHA-256 `0edeca29…6ea6e08b`)

Full SHA-256 values are recorded in `screenshots/clickthrough-report.json`
under `referenceHashes`. Per the README, the two screens are user-approved
visual direction without exact measurements, and the concept board is
generated inspiration; nothing below copies non-authoritative controls or
implies later timeline, media, rendering, or export capability.

| Dimension | Finding | Basis in actual Product v1 captures |
| --- | --- | --- |
| Visual hierarchy | **INTENTIONAL ADAPTATION** | The create reference's 4-step grammar-first layout (script + grammar + art style + voice/format pickers) was deliberately superseded by the accepted F3-WP4 two-path single-template flow, which is exactly the concept board's panel 1 ("Create your story — Start in two simple ways"). `wp5-1440x900-create-choice.png` matches that intent: one template card, exactly **Paste a script** and **What's your idea?**, both converging on the one shared review gate (`wp5-1440x900-paste-proposal-review.png`, `wp5-1920x1080-idea-proposal-review.png`). No Weird History, no pickers, no placeholder options. |
| Board primacy | **MATCH** | At 1920×1080 (`wp5-1920x1080-studio.png`) and 1440×900 (`wp5-1440x900-studio-ai-proposal.png`) the visual board — scene heading, beat card, reference art, playhead, transport — is the large central surface between the hierarchy rail and the Director inspector, with the AI Director docked right. At 1024×800 the rail remains first for keyboard/context order but is capped as its own scroll region, so the board begins at y=476 inside the first viewport (`wp5-1024x800-studio-keyboard-focus.png`). This retains canvas-first orientation without hiding hierarchy. The episode-overview strip sits below, standing in for the reference's compact beat strip. |
| Panel density | **MATCH** | The AI Director is one compact docked column (330 px at ≥1025 px, full-width stacked at 1024) carrying the fixture label, scope line, shot/character honesty labels, one scrubber, the thread, and the composer — the density of the reference's right-side Director conversation, never a terminal or detached console. Connection detail stays collapsed inside Settings → AI Director behind the one truthful chip, matching the README's "one compact truthful header state; advanced details collapsed in Settings." |
| Scope visibility | **MATCH** | The README requires the chat scope to be always visible and never silently widened. The actual surfaces pin scope three ways: the permanent scope header (episode / sequence / scene / beat) above every Studio surface; the panel's own scope line plus honest shot/character labels; and the immutable captured-scope chips (Scene · Beat · Playhead · Range) attached to every request and proposal (`wp5-1440x900-studio-ai-proposal.png`, `wp5-1024x800-studio-ai-proposal.png`). The AI proposal can never retarget after send. |
| Proposal comprehension | **INTENTIONAL ADAPTATION** | The concept board's before/after image thumbnails, impact percentages, and emotion/focus/pacing deltas are non-authoritative — no production assets or metrics exist to preview — so they are not copied. The actual proposal carries the honest structured equivalent: summary, exactly one proposed `performanceDirection`, affected range, affected assets (session-local metadata only), time-anchored markers, bounded E1 fixture tool labels, an explicit text before/after **Preview** ("no direction has changed"), and **Revise / Reject / Apply / Undo** with fail-closed guards (`wp5-1440x900-studio-ai-proposal.png`). Jargon-free outcome states (complete, cancelled, error, superseded, applied, rejected, undone) remain distinguishable by text, not color alone. |
| Typography | **MATCH** | The README supplies no numeric type spec, so fidelity is to the approved screens' visible ramp: dark theme, display-weight headings over compact uppercase micro-labels, 11–13 px panel text. The captures show the same ramp on Create, review, and Studio at all three viewports; required-text contrast was accepted at F1 and is unchanged by this package. |
| Compact ordering | **INTENTIONAL ADAPTATION** | The README permits the Director to collapse into a labelled drawer and the rail/timeline to collapse progressively. The accepted F2-WP3 compact contract instead stacks all four regions at 1024×800: rail (selection context) → board → inspector (Director) → AI panel. F3-WP5 caps the rail at 300 px with internal keyboard-safe scrolling so the board remains visible in the first viewport. The full Create choice, shared review, final review actions, settings, keyboard focus, proposal, reduced-motion, and offline/error states are independently captured at 1024×800. Machine checks prove no document-level horizontal overflow, clipping, overlapping sticky regions, or unreachable final actions. A drawer was not introduced because every region must stay reachable and understandable without one; truth disclosures, scope, errors, and proposal consequences are never hidden to fit. |
| Timeline, tracks, media, export | **DEFERRED OUTSIDE F3** | The studio-timeline reference's waveform/camera/voice/SFX tracks, Fit/zoom transport, and Preview/Export actions, and the create reference's grammar/art-style/voice pickers, are later-package capabilities. The actual surfaces keep Preview and Export visibly disabled with honest reasons, the playhead labelled local UI timing (not media playback), and every AI surface labelled **Local AI Director fixture — no service connected** (`wp5-1440x900-studio-manual-direction.png`, `wp5-1440x900-ai-error-offline-truth.png`). |
