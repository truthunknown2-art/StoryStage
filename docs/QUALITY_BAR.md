# Quality bar

A StoryStage ticket is complete only when:

- process and package boundaries stay explicit and schema-validated;
- Remotion output is frame-driven and offline-capable;
- browser and desktop capability differences are represented by host adapters;
- lint, strict type-checking, unit tests, and production builds pass;
- a real media render is inspected and its metadata is recorded;
- determinism is checked through two renders and representative extracted-frame hashes;
- worker failure leaves the studio responsive with a visible retry path;
- artifacts, limitations, deviations, and the proposed next ticket are documented.
