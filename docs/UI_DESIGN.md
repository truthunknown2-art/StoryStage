# UI design

The SS-001 shell uses dark charcoal surfaces, warm ivory text, a restrained amber action accent, blue for proposed material, green for approved state, and red only for failures. CSS tokens define the palette and spacing.

The productions screen exposes the StoryStage heading, Show Pack metadata, status, duration, episode entry point, and compact queue. The workspace keeps production navigation left, 16:9 preview center, inspector right, scenes and visible shots below the stage, and a semantic timeline at the bottom. Browser mode never fakes a render; desktop failures show a Retry control.
